# Модули JavaScript

- `app.js` — единая точка входа.
- `modules/navigation.js` — компактная мобильная шапка и навигация по разделам внизу экрана.
- `modules/clock.js` — время, день недели и дата по часовому поясу посетителя.
- `modules/carousel.js` — слайдер проектов: цикл, стрелки, клавиатура и свайп.
- `modules/project-preview.js` — модальное окно с длинным снимком проекта и увеличением.
- `modules/tabs.js` — доступные вкладки и управление стрелками.
- `modules/reveal.js` — плавное появление секций при прокрутке.

Модули подключаются стандартным `import` из ES6+. Если добавляете новую функцию, создайте отдельный модуль и импортируйте его в `app.js`.
